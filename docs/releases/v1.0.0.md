# CWidget v1.0.0 — first public release
A currency-converter tray widget for Windows and Linux: instant conversion, favorites, two rate sources with failover, dark/light themes, RU/EN UI.

# Highlights
- Reliable tray backend — a self-contained Win32 implementation onWindows (the third-party tray library had a recurring failure where the icon stopped responding); every tray event is logged.
- Fresh rates, honestly — rates are published once per working day by the sources; the widget chases the publication (a check right after it,then every 15 minutes), deduplicates by quote date, and always shows when it fetched and which date the quotes carry.
- Failover & offline — selected source → fallback → per-source cached snapshots (valid for one day) → honest "no connection"; every degradation is visible (⚠ badge, tray tooltip, toasts).
- Converter UX — bidirectional input, live thousands grouping, smart Backspace/Delete around separators, swap amounts+currencies / swap currencies.
- Favorites — star currencies once, they pin to the top of every dropdown across providers.
- Window — remembers its position (multi-monitor safe), optional stay-on-top, rounded corners (native DWM on Win11), no taskbar button.
- Autostart, self-uninstall, full diagnostics log (cwidget.log).

# Known limitations
- Windows 10: slightly stepped window corners (no system rounding beforeWin11).
- Linux: menu opens on any tray click in most DEs (AppIndicator protocol limitation); taskbar hiding needs X11 + wmctrl.
- ECB-based sources do not publish RUB/KZT — those pairs fail over or are served from the cached snapshot.
- Binaries are not code-signed (SmartScreen warning on first launch).
