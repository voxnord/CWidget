# CWidget v1.0.0 — first public release
A currency-converter tray widget for Windows and Linux: instant conversion,favorites, two rate sources with failover, dark/light themes, RU/EN UI.

# Highlights
- Reliable tray backend — a self-contained Win32 implementation onWindows (the third-party tray library had a recurring failure where theicon stopped responding); every tray event is logged.
- Fresh rates, honestly — rates are published once per working day bythe sources; the widget chases the publication (a check right after it,then every 15 minutes), deduplicates by quote date, and always showswhen it fetched and which date the quotes carry.
- Failover & offline — selected source → fallback → per-source cachedsnapshots (valid for one day) → honest "no connection"; everydegradation is visible (⚠ badge, tray tooltip, toasts).
- Converter UX — bidirectional input, live thousands grouping, smartBackspace/Delete around separators, swap amounts+currencies / swapcurrencies.
- Favorites — star currencies once, they pin to the top of everydropdown across providers.
- Window — remembers its position (multi-monitor safe), optionalstay-on-top, rounded corners (native DWM on Win11), no taskbar button.
- Autostart, self-uninstall, full diagnostics log (cwidget.log).

# Known limitations
- Windows 10: slightly stepped window corners (no system rounding beforeWin11).
- Linux: menu opens on any tray click in most DEs (AppIndicator protocollimitation); taskbar hiding needs X11 + wmctrl.
- ECB-based sources do not publish RUB/KZT — those pairs fail over or areserved from the cached snapshot.
- Binaries are not code-signed (SmartScreen warning on first launch).
